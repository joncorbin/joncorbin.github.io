Complaint Resolution AI

AI agents · side project

Describe a dispute with a company in plain English. A team of AI agents turns it into a case analysis, a negotiation plan, a ready-to-send complaint and an escalation plan.

Why
When a company stonewalls you, it's hard to know what your options are or who to escalate to.
What I built
  • A typed multi-agent pipeline in Python, with Pydantic models passed between every step.
  • FastAPI endpoints and a Streamlit demo anyone can click through.
  • Deterministic policy retrieval and an offline fallback, so it still works without the LLM.
  • 74 automated tests.
  • Python
  • Pydantic
  • FastAPI
  • Streamlit
  • Anthropic API

Rollout → Linear automation

Integration · at Maven AGI

Reads customer rollout emails and files them as Linear issues, routed to the right team and project. It has filed 1,000+ issues so far.

Why
Rollout requests arrive by email, but the team tracks work in Linear. Copying them over by hand doesn't scale.
What I built
  • A Google Apps Script job that parses incoming rollout emails.
  • Routing rules that pick the right Linear team and project for each request.
  • A Linear API integration that creates the issues.
  • A persistent processing ledger, so re-running the job never creates duplicates.
  • Google Apps Script
  • Linear API
  • Google Workspace

Internal tool, so there's no public source.

Full-stack · side project

Free things happening near you, right now. Sign in, share your location, and see nearby events posted by other users and pulled from Ticketmaster.

What I built
  • A Next.js app with Clerk sign-in.
  • PostGIS geospatial search to find events within a radius of you.
  • User-submitted events alongside a Ticketmaster API integration.
